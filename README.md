# All4Ruse v2

All4Ruse v2 is a rewrite of the All4Ruse platform — a modern events discovery platform for Ruse, Bulgaria.

The goal of v2 is to build a cleaner, more scalable, and more maintainable product with better architecture, stronger typing, improved UX/UI, and room for a more capable backend.

## Goals

- Build a modern, scalable codebase from scratch.
- Improve maintainability and developer experience.
- Improve design quality and consistency.
- Improve performance, SEO, and accessibility.
- Support future backend/admin workflows more cleanly.
- Create a stronger foundation for organizers, promotions, and future monetization.

## Product vision

All4Ruse helps people in Ruse discover what is happening in the city — concerts, theatre, parties, exhibitions, festivals, kids events, cultural events, and other local experiences — in one place.

The platform should feel modern, local, trustworthy, useful, and easy to browse.

## Planned stack

This is the initial preferred stack and may be refined as the architecture is finalized:

- Next.js
- TypeScript
- React
- Tailwind CSS
- Shadcn
- ESLint
- Prettier

## Development principles

- TypeScript-first codebase.
- Strong focus on readability and maintainability.
- Minimal, low-risk changes by default.
- Architecture and business logic should be explicit, not guessed.
- Refactors should be intentional and planned.

## Initial focus

The first phase of v2 is to define:
- product requirements
- architecture
- project structure
- design direction
- data model
- implementation phases

Application code should be generated only after the foundation is clearly defined.
